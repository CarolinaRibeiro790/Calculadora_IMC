## 🚀 Sobre o Projeto
Este projeto é uma Calculadora de IMC (Índice de Massa Corporal) desenvolvida durante o curso de React Native da Onebithealth no YouTube. O objetivo foi aprender os fundamentos do React Native, incluindo a renderização de elementos na tela e a implementação de funcionalidades básicas de cálculo.

## 🛠️ Tecnologias Utilizadas
<li>React Native: Para desenvolvimento do aplicativo.
<li>JavaScript: Para lógica do cálculo do IMC.

## 📝 Funcionalidades
<li>Cálculo do IMC com base no peso e altura fornecidos pelo usuário.
<li>Renderização dinâmica do resultado diretamente na tela.
<li>Projeto simples e direto, sem uso de componentes personalizados.

## 📚 Aprendizados
Durante o desenvolvimento deste projeto, foram explorados os seguintes conceitos:
<li>Configuração inicial de um projeto React Native.
<li>Renderização de elementos diretamente no componente principal.
<li>Implementação da lógica para o cálculo do IMC.
<li>Integração de entradas do usuário e exibição de resultados.
